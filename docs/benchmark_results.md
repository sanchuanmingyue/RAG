# Benchmark 结果说明

## Open RAG Benchmark

评测在 100 条查询、200 篇论文语料、Top-5 返回结果的固定配置下进行。Baseline 使用向量与关键词混合检索；当前链路增加两阶段候选筛选、章节级索引、章节聚合和重排序。

| 指标 | Hybrid Baseline | 两阶段检索 | 当前完整链路 |
| --- | ---: | ---: | ---: |
| Doc Recall@5 | 100.00% | 99.00% | **100.00%** |
| Section Recall@5 | 78.00% | 93.00% | **97.00%** |
| Section MRR | 0.6395 | 0.7882 | **0.8433** |
| P50 检索延迟 | 4.15 s | **0.86 s** | 2.26 s |
| P95 检索延迟 | 7.68 s | **1.17 s** | 5.80 s |

完整链路在提升章节级召回与排序质量的同时引入 Reranker，因此比轻量两阶段版本延迟更高，但仍低于 Baseline。项目可根据在线场景在“低延迟”与“高精度”配置间切换。
